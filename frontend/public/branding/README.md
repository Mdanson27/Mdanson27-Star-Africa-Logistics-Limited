# Star Africa branding assets

Add these three files to this folder using the exact filenames below:

1. `star-africa-logo.png` — full horizontal/primary logo.
2. `star-africa-logo-compact.png` — compact logo for smaller UI placements.
3. `star-africa-mark.png` — standalone mark for icons/favicons/collapsed navigation.

The application already references these paths through `frontend/src/config/brand.ts`. Do not rename the files unless you also update that configuration.
